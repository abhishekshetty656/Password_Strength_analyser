# Password Strength Analyzer

## Overview
Password Strength Analyzer is a simple Python project that checks whether a password is strong, medium, or weak. It helps users create secure passwords by analyzing different security conditions.

This project is beginner-friendly and useful for understanding Python functions, conditions, and regular expressions.

---

## Features
- Checks password length
- Detects uppercase letters
- Detects lowercase letters
- Detects numbers
- Detects special characters
- Displays password strength
- Provides suggestions to improve weak passwords

---

## Technologies Used
- Python
- Regular Expressions (re module)
