# Password Strength Analyzer

## 📌 Project Description

Password Strength Analyzer is a Python-based project that checks whether a password is weak, medium, or strong based on different security conditions.

The project helps users improve password security by providing suggestions for creating stronger passwords.

---

## 🚀 Features

* Checks password length
* Detects uppercase letters
* Detects lowercase letters
* Detects numbers
* Detects special characters
* Displays password strength
* Gives improvement suggestions

---

## 🛠️ Technologies Used

* Python
* Regular Expressions (`re` module)
